Privacy

FieldCall stores the event information you submit: event name, selected address when available, coordinates, event time window, and weather limits. Event records and forecast check history are associated with the Google account subject that signed in.

Google sign-in returns your account name, email address, and stable account identifier. FieldCall requests basic sign-in information only; it does not request Gmail, Drive, or contacts access. If you use address lookup, the address text is sent to Google Maps Geocoding to resolve a location. The chosen coordinates are sent to MET Norway to request the forecast.

FieldCall stores event records and forecast check history in its application database. The current product has no in-app event deletion control or automatic retention schedule. The hosting environment may not retain local database files across service restarts unless persistent storage is configured.

FieldCall does not currently use advertising trackers or analytics. The service uses essential session cookies for Google sign-in. External providers process requests under their own terms and privacy policies.

For project questions or a data request, contact the project through the FieldCall GitHub repository. Do not include sensitive account information in a public issue.
